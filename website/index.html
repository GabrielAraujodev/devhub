100% Local & Privado

Zero poluição de código

O DevHub não cria arquivos ocultos, arquivos de configuração invasivos ou metadados dentro das suas árvores de repositórios. Seus commits Git permanecem imaculados.

Padrão CamaraUX Design System

Base matemática de espaçamento 8px, conformidade de contraste estrito WCAG AA (> 4.5:1), feedback não-bloqueante por toasts e tolerância zero para becos sem saída.

Suporte Nativo a CLIs de IA

Lançamento em 1 clique de Claude Code, Aider, Cursor, Antigravity (AGY) e Ollama diretamente na raiz do repositório, com histórico e caminhos personalizados.

Clean Architecture Nativa

Zero Electron. Zero Node no background. 100% C++20.

O DevHub foi estruturado sob os princípios de Clean Architecture e separação de domínios. Uma camada de Core pura em C++20, persistência com SQLite nativo via `QSqlDatabase` e UI acelerada por hardware via Qt6 Widgets.

Renderização de alta fidelidade baseada em tokens CamaraUX com WCAG AA, tabela responsiva e feedbacks não-bloqueantes.
